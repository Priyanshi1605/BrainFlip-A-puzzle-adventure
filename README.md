# 🧩 BrainFlip: A Puzzle Adventure

BrainFlip is an interactive, immersive web-based puzzle adventure game designed with polished visuals and smooth animations. Players engage with various cognitive challenges, track their progression, and unlock new puzzle modules in a beautifully designed UI.

## 🚀 Live Demo
Check out the live deployment of the game here:
👉 **[Play BrainFlip Live](https://github.io)**

---

## 🛠️ Technical Stack

This project is built using a modern, lightweight web development stack optimized for speed and fluid interface rendering:

- **Frontend Framework:** [React](https://react.dev) (Functional components with hooks for local state management)
- **Build Tool & Bundler:** [Vite](https://vite.dev) (Ensures near-instant server starts and hyper-fast Hot Module Replacement)
- **Styling Pipeline:** [Tailwind CSS v4](https://tailwindcss.com) (Utility-first framework for rapid interface styling)
- **Language Platform:** [TypeScript](https://typescriptlang.org) / JavaScript (Ensures type safety and component structure stability)
- **CI/CD Deployment:** [GitHub Actions](https://github.com) (Automated workflows compilation directly to GitHub Pages)

---

## ✨ Features
- **Fluid Visual Flow:** Responsive layouts with custom asset resolutions adapted directly from vector prototypes.
- **Dynamic Localization Structures:** Built-in modular configurations ready for quick locale switching (such as UK/US profile variations).
- **Clean Architecture:** Standardized relative asset bundling allowing the game to host seamlessly on any subdirectory base path.
- **No Heavy Backends:** Zero tracking overhead for a lightweight, instant-loading user experience.

## 💻 Local Development Setup

To run this project locally on your machine, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd BrainFlip-A-puzzle-adventure/BrainFlip
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build the production bundle:**
   ```bash
   npm run build
   ```
